Fix It Fast

Something went red? Tap the message that looks like yours. Each fix is copy, paste, Enter.

The golden rule: after anything installs, close PowerShell and open a new one. Half of all errors disappear with a fresh window. And always type codex.cmd, not just codex.

Node (the thing Codex runs on) is not installed yet, or PowerShell has not noticed it yet.

  1. Install Node:
    Runwinget install --id OpenJS.NodeJS.LTS -e
  2. Close PowerShell completely and open a new one.
  3. Install Codex using Node's full address (works even if Windows still can't find Node):
    Run& "C:\Program Files\nodejs\npm.cmd" install -g @openai/codex
  4. Check it:
    Checkcodex.cmd --version
Shows a version number? Done. Close PowerShell, open a new one, and run the shortcut line from the install page again to finish everything else.

Codex is installed but Windows does not know where to find it yet.

  1. Tell Windows where it lives:
    Fix[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:APPDATA\npm", "User")
  2. Close PowerShell and open a new one.
  3. Check:
    Checkcodex.cmd --version
Still not recognised? Install Codex again with:
Run& "C:\Program Files\nodejs\npm.cmd" install -g @openai/codex

Windows is blocking small helper scripts. This one line allows them for your account only (no administrator needed):

FixSet-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
Then close PowerShell, open a new one, and try again.
