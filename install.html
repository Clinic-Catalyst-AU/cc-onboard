Clinic Catalyst

Install Your Claude

Claude, the tools it needs, and the full Clinic Catalyst system, installed piece by piece. Copy, paste, check, next.

Before you start
  • Laptop plugged in and on good wifi. Allow about 45 minutes.
  • A paid Claude plan (Pro or Max). Make sure you can log in at claude.ai.
  • Your Mac login password handy (the one you use to unlock your laptop).
The rhythm: hit Copy, click into the window, paste, press Enter, and wait until the cursor comes back before the next one. Check lines prove each piece went in.

Shortcut: one line does steps 1 to 6

Open Terminal (hold Command, tap Spacebar, type Terminal, press Enter) and paste this. It installs everything below in order and checks it at the end. If it finishes with DONE - everything installed and verified, jump to step 7. If anything says MISSING, do just that piece below.

Runcurl -fsSL https://clinic-catalyst-au.github.io/cc-onboard/clinic-bootstrap.sh | bash
Piece by piece

1 Claude Code

The main app. Puts Claude on your laptop.
Runcurl -fsSL https://claude.ai/install.sh | bash
Checkclaude --version
"command not found: claude"? Run this, then check again:
Fixecho 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zprofile && source ~/.zprofile

2 Homebrew

The Mac's app installer. The tools below all come through it.
Run/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Asked for a password? Type your Mac login password and press Enter. Nothing shows while you type. That's normal.
"Press RETURN to continue"? Press Enter. It may also install Apple's command line tools first, which takes a few minutes.
Then make the Mac remember where Homebrew lives (Apple chip Macs, M1 to M4):
Runecho 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)"
Checkbrew --version
Older Intel Mac? Use this instead of the line above. (Not sure? uname -m says arm64 for Apple chip, x86_64 for Intel.)
Intelecho 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/usr/local/bin/brew shellenv)"

3a Node

Runs the video editing engine.
Runbrew install node
Checknode -v

3b Python

Runs the covers, captions and website-scanning tools.
Runbrew install python
Checkpython3 --version

3c Git

Lets Claude keep versions of your files.
Runbrew install git
Checkgit --version

3d FFmpeg

Cuts, joins and captions your videos and reels.
Runbrew install ffmpeg
Checkffmpeg -version
Takes a while. 5 to 10 minutes is normal.

3e ImageMagick

Makes and resizes images and covers.
Runbrew install imagemagick
Checkmagick -version

4 Python helpers

Image making, web requests, spreadsheets and video trimming.
Runpython3 -m pip install --break-system-packages Pillow requests playwright openpyxl auto-editor
Checkpython3 -c "import PIL, requests; print('all good')"

5 Whisper (free captions on your laptop)

Turns speech in your videos into captions without sending them anywhere.
Apple chippython3 -m pip install --break-system-packages mlx-whisper
Intelpython3 -m pip install --break-system-packages faster-whisper

6 The Clinic Catalyst system

Every Clinic Catalyst skill, your ~/Clinic workspace with its Business Brain folder, and the reel engine. Safe to run again: it never touches your own work.
Runcd "$(mktemp -d)" && curl -fsSL https://clinic-catalyst-au.github.io/cc-onboard/cc-clinic-pack.zip -o pack.zip && unzip -q pack.zip && bash cc-clinic-pack/INSTALL.sh
Checkls ~/.claude/skills | grep cc- && ls ~/Clinic
You should see a list of cc- skill names and your Clinic folders (Business-Brain, Content, Emails, Ads).

7 Start Claude in your Clinic folder

Press Command + Q to fully quit the Terminal and open a fresh one. Then:
Startcd ~/Clinic && claude
The first time, Claude asks you to sign in: choose your Claude account, a browser opens, click Authorize, then come back to the Terminal.

Shortcut: one line does steps 1 to 8

Piece by piece
After each install, close PowerShell and open a new one before the Check line, so Windows sees the new program. If Windows asks "Do you want to allow this app to make changes?", click Yes.

1 Git for Windows

Claude Code on Windows needs this first.
Runwinget install --id Git.Git -e --source winget
Checkgit --version
"winget is not recognised"? Open the Microsoft Store, search App Installer, update it, then reopen PowerShell.

2 Claude Code

The main app. Puts Claude on your computer.
Runirm https://claude.ai/install.ps1 | iex
Checkclaude --version
"claude is not recognised"? Run this, close and reopen PowerShell, check again:
Fix[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")

3 Node

Runs the video editing engine.
Runwinget install --id OpenJS.NodeJS.LTS -e
Checknode -v

4 Python

Runs the covers, captions and website-scanning tools.
Runwinget install --id Python.Python.3.12 -e
Checkpython --version
Typing python opens the Microsoft Store? Go to Settings > Apps > Advanced app settings > App execution aliases, turn OFF both "python" and "python3", then reopen PowerShell.

Cuts, joins and captions your videos and reels.
