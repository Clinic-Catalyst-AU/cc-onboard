Clinic Catalyst

Install Your Codex

For clinics using ChatGPT. Codex, the tools it needs, and the full Clinic Catalyst system on your Windows computer. Copy, paste, check, next.

Before you start
  • Laptop plugged in and on good wifi. Allow about 45 minutes.
  • A paid ChatGPT plan (Plus or Pro). Make sure you can log in at chatgpt.com.
  • This page is for Windows computers.
  • If Windows asks for an administrator password while installing, enter it (or ask whoever set up the computer).
The rhythm: hit Copy, click into the PowerShell window, paste, press Enter, and wait until the cursor comes back before the next one. Check lines prove each piece went in.

Shortcut: one line does steps 1 to 7

Click Start, type PowerShell, open Windows PowerShell the normal way (not "Run as administrator") and paste this. It installs everything below and checks it at the end. If every line shows ok, jump to step 8. If anything says MISSING, do just that piece below.

Runirm https://clinic-catalyst-au.github.io/cc-onboard/clinic-codex-bootstrap.ps1 | iex
Got an error? Open the Fix It page
Piece by piece
Paste each Run block, wait until the cursor comes back, then paste its Check. Only move on when Check looks right. Blocks with several lines: paste the whole block at once. You do not need to close PowerShell between steps. If a command "is not recognised", paste this refresh line and try again:
Refresh$env:Path = [Environment]::ExpandEnvironmentVariables(([Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + [Environment]::GetEnvironmentVariable('Path', 'User')))

Fix& { if (-not (Test-Path -LiteralPath 'C:\Program Files\nodejs\npm.cmd')) { throw 'Node did not install at the required location. Repeat Run and finish the installer, including any Windows approval prompt.' } $nodeDir = 'C:\Program Files\nodejs' $userPath = [Environment]::GetEnvironmentVariable('Path', 'User') if (($userPath -split ';') -notcontains $nodeDir) { [Environment]::SetEnvironmentVariable('Path', ($nodeDir + ';' + $userPath), 'User') } $env:Path = [Environment]::ExpandEnvironmentVariables(([Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + [Environment]::GetEnvironmentVariable('Path', 'User'))) npm.cmd --version }

4 Python

Install Python so your clinic tools can work with pictures, websites and recordings.
Runwinget.exe install --id Python.Python.3.12 --exact --source winget --scope user --architecture x64 --custom 'InstallLauncherAllUsers=0' --accept-package-agreements --accept-source-agreements $env:Path = [Environment]::ExpandEnvironmentVariables(([Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + [Environment]::GetEnvironmentVariable('Path', 'User')))
Check& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" --version & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m pip --version
Good looks like: Python 3.12.x appears, followed by a pip version associated with Python 3.12.
Use this if typing python opens Microsoft Store or reports that Python was not found; the full-path commands in Check and step 6 bypass those aliases.
Fix& { $pythonDir = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python312' if (-not (Test-Path -LiteralPath (Join-Path $pythonDir 'python.exe'))) { throw 'Python is missing from its expected location. Repeat Run and finish the installation.' } $userPath = [Environment]::GetEnvironmentVariable('Path', 'User') foreach ($entry in @($pythonDir, (Join-Path $pythonDir 'Scripts'))) { if (($userPath -split ';') -notcontains $entry) { $userPath = $entry + ';' + $userPath } } [Environment]::SetEnvironmentVariable('Path', $userPath, 'User') $env:Path = [Environment]::ExpandEnvironmentVariables(([Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + [Environment]::GetEnvironmentVariable('Path', 'User'))) Start-Process 'ms-settings:appsfeatures-appexecutionalias' Write-Host 'In App execution aliases, turn OFF the App Installer entries for python.exe and python3.exe. If this page does not open, search Start for Manage app execution aliases.' & (Join-Path $pythonDir 'python.exe') --version }

5 FFmpeg

Install the tool that processes video and audio files.
Runwinget.exe install --id Gyan.FFmpeg --exact --source winget --scope user --accept-package-agreements --accept-source-agreements $env:Path = [Environment]::ExpandEnvironmentVariables(([Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + [Environment]::GetEnvironmentVariable('Path', 'User')))
Checkffmpeg.exe -version ffprobe.exe -version
Good looks like: Both commands show version information.
Use this standalone download fallback if winget fails or FFmpeg is still not recognized after refreshing PATH.
Fix& { $ErrorActionPreference = 'Stop' [Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12 $workDir = Join-Path $env:TEMP ('cc-ffmpeg-' + [guid]::NewGuid().ToString('N')) $binDir = Join-Path $env:LOCALAPPDATA 'Programs\FFmpeg\bin' New-Item -ItemType Directory -Path $workDir -Force | Out-Null New-Item -ItemType Directory -Path $binDir -Force | Out-Null $zipPath = Join-Path $workDir 'ffmpeg.zip' Invoke-WebRequest -UseBasicParsing -Uri 'https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip' -OutFile $zipPath Expand-Archive -LiteralPath $zipPath -DestinationPath (Join-Path $workDir 'extracted') -Force foreach ($name in @('ffmpeg.exe', 'ffprobe.exe')) { $file = Get-ChildItem -LiteralPath (Join-Path $workDir 'extracted') -Recurse -File -Filter $name | Select-Object -First 1 if ($null -eq $file) { throw "The download did not contain $name." } Copy-Item -LiteralPath $file.FullName -Destination (Join-Path $binDir $name) -Force } $userPath = [Environment]::GetEnvironmentVariable('Path', 'User') if (($userPath -split ';') -notcontains $binDir) { [Environment]::SetEnvironmentVariable('Path', ($binDir + ';' + $userPath), 'User') } $env:Path = [Environment]::ExpandEnvironmentVariables(([Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + [Environment]::GetEnvironmentVariable('Path', 'User'))) & (Join-Path $binDir 'ffmpeg.exe') -version & (Join-Path $binDir 'ffprobe.exe') -version }

7 The Clinic Catalyst skills + your Clinic folder

Download your clinic skills and create your clinic workspace while preserving any existing AGENTS.md.
Run& { $ErrorActionPreference = 'Stop' [Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12 $workDir = Join-Path $env:TEMP ('cc-clinic-pack-' + [guid]::NewGuid().ToString('N')) New-Item -ItemType Directory -Path $workDir -Force | Out-Null $zipPath = Join-Path $workDir 'cc-clinic-pack.zip' $extractDir = Join-Path $workDir 'extracted' Invoke-WebRequest -UseBasicParsing -Uri 'https://clinic-catalyst-au.github.io/cc-onboard/cc-clinic-pack.zip' -OutFile $zipPath Expand-Archive -LiteralPath $zipPath -DestinationPath $extractDir -Force $packDir = Join-Path $extractDir 'cc-clinic-pack' $sourceSkills = Join-Path $packDir 'skills' $template = Join-Path $packDir 'templates\clinic-CLAUDE.md' if (-not (Test-Path -LiteralPath $sourceSkills -PathType Container)) { throw 'The ZIP is missing cc-clinic-pack\skills.' } if (-not (Test-Path -LiteralPath $template -PathType Leaf)) { throw 'The ZIP is missing templates\clinic-CLAUDE.md.' } $skillsDir = Join-Path $HOME '.agents\skills' New-Item -ItemType Directory -Path $skillsDir -Force | Out-Null Copy-Item -Path (Join-Path $sourceSkills '*') -Destination $skillsDir -Recurse -Force $clinicDir = Join-Path $HOME 'Clinic' foreach ($folder in @('Business-Brain\brand-assets', 'Content', 'Emails', 'Ads')) { New-Item -ItemType Directory -Path (Join-Path $clinicDir $folder) -Force | Out-Null } $agentsFile = Join-Path $clinicDir 'AGENTS.md' if (-not (Test-Path -LiteralPath $agentsFile)) { Copy-Item -LiteralPath $template -Destination $agentsFile } Write-Host 'Clinic Catalyst skills and clinic folders are installed.' }
Check$skillsDir = Join-Path $HOME '.agents\skills' $skillCount = @(Get-ChildItem -LiteralPath $skillsDir -Directory -Filter 'cc-*' -ErrorAction SilentlyContinue | Where-Object { Test-Path -LiteralPath (Join-Path $_.FullName 'SKILL.md') -PathType Leaf }).Count Write-Output ('cc- skills: ' + $skillCount) Write-Output ('AGENTS.md exists: ' + (Test-Path -LiteralPath (Join-Path $HOME 'Clinic\AGENTS.md') -PathType Leaf))
Good looks like: cc- skills shows a number greater than zero and AGENTS.md exists shows True.
