Install Your Codex

For clinics using ChatGPT. Codex, the tools it needs, and the full Clinic Catalyst system on your Windows computer. Copy, paste, check, next.

Before you start
  • Laptop plugged in and on good wifi. Allow about 45 minutes.
  • A paid ChatGPT plan (Plus or Pro). Make sure you can log in at chatgpt.com.
  • This page is for Windows computers.
  • If Windows asks for an administrator password while installing, enter it (or ask whoever set up the computer).
The rhythm: hit Copy, click into the PowerShell window, paste, press Enter, and wait until the cursor comes back before the next one. Check lines prove each piece went in.

Shortcut: one line does steps 1 to 8 (except the optional ImageMagick)

Click Start, type PowerShell, open Windows PowerShell the normal way (not "Run as administrator") and paste this. It installs everything below and checks it at the end. If every line shows ok, jump to step 9. If anything says MISSING, do just that piece below.

Runirm https://clinic-catalyst-au.github.io/cc-onboard/clinic-codex-bootstrap.ps1 | iex
Piece by piece
After each install, close PowerShell and open a new one before the Check line, so Windows sees the new program. If Windows asks "Do you want to allow this app to make changes?", click Yes.

1 Git for Windows

Lets Codex keep versions of your files.
Runwinget install --id Git.Git -e --source winget
Checkgit --version
"winget is not recognised"? Open the Microsoft Store, search App Installer, update it, then reopen PowerShell.

2 Node

Codex runs on it, and so does the video engine.
Runwinget install --id OpenJS.NodeJS.LTS -e
Checknode -v

3 Codex

The main app. Puts Codex on your computer.
Runnpm.cmd install -g @openai/codex
Checkcodex.cmd --version
Always type codex.cmd (not just codex) in PowerShell. Windows blocks the short version by default.
"codex.cmd is not recognised"? Run this, close and reopen PowerShell, check again:
Fix[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:APPDATA\npm", "User")

4 Python

Runs the covers, captions and website-scanning tools.
Runwinget install --id Python.Python.3.12 -e
Checkpython --version
Typing python opens the Microsoft Store? Go to Settings > Apps > Advanced app settings > App execution aliases, turn OFF both "python" and "python3", then reopen PowerShell.

5 FFmpeg

Cuts, joins and converts video and audio.
Runwinget install --id Gyan.FFmpeg -e
Checkffmpeg -version
Still "not recognised" after reopening? Run the shortcut line at the top. It puts FFmpeg somewhere Windows can always find it.

6 ImageMagick (optional)

Makes and resizes images and covers.
Runwinget install --id ImageMagick.ImageMagick -e
Checkmagick -version

7 Python helpers + Whisper

Image making, web requests, and free captions on your computer.
Runpython -m pip install --user Pillow requests playwright faster-whisper
Checkpython -c "import PIL, requests, faster_whisper; print('all good')"

8 The Clinic Catalyst system

Every Clinic Catalyst skill where Codex finds them, your Clinic workspace with its Business Brain folder and rules file, and the video engine. This comes through the shortcut line. It skips the tools you already installed above, refreshes the skills, and leaves your own clinic files alone.
Runirm https://clinic-catalyst-au.github.io/cc-onboard/clinic-codex-bootstrap.ps1 | iex
Checkls ~\.agents\skills; ls ~\Clinic
You should see a list of cc- skill names, and your Clinic folders with an AGENTS.md file.

9 Start Codex in your Clinic folder

Close PowerShell and open a fresh one. Then:
Startcd ~\Clinic; codex.cmd
The first time, choose Sign in with ChatGPT. A browser opens, log in with your ChatGPT account, then come back to PowerShell. If Codex asks whether to trust this folder, or to set up its safe workspace on Windows, say yes and follow its steps.
Inside Codex
In Codex you just ask in plain words. Mention the skill by name and it does the rest.

✓ Teach Codex your clinic

Type this into Codex and press Enter. It asks you questions about your clinic, your clients and how you talk.
TypeUse the cc-resonance skill to learn my clinic. Ask me the questions one at a time.

✓ Set up your brand

When that is finished, send this one. It captures your colours, fonts and look so everything Codex makes looks like you.
TypeUse the cc-brand-guide skill to build my brand guide.

You're in 🎉

Codex now knows your clinic and has the Clinic Catalyst system ready to go.
